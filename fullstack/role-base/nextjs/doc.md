| **Title**  | **File Name**   | **Description**                                                     |
| ---------- | --------------- | ------------------------------------------------------------------- |
| Middleware | `middleware.ts` | Handles global or route-specific middleware logic.                  |
| Layout     | `layout.tsx`    | Defines a common layout for a page or route.                        |
| Loading    | `loading.tsx`   | Displays a loading spinner or placeholder while content is loading. |
| Error      | `error.tsx`     | Shows a custom error message if an error occurs on that page.       |
| 404 Page   | `not-found.tsx` | Provides a custom 404 page when a route is not found.               |
| Head       | `head.tsx`      | Adds custom meta tags or titles to the page’s `<head>` section.     |
